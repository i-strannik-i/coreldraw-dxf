# CorelDRAW DXF

Самостоятельный проект экспорта из CorelDRAW в DXF для отдела дизайна.
Не зависит от проекта склада или установленного Aspire.

## Установка

Бета для тестирования: [SetupCorelDXF-0.11.20.exe](https://github.com/i-strannik-i/coreldraw-dxf/releases/download/v0.11.20/SetupCorelDXF-0.11.20.exe).

Экспорт использует общую проверку исходного документа: переносит дубли, показывает
результаты во вкладке «Проверка» и затем создаёт DXF из временной копии. При возврате
найденные места уже доступны для выделения и меток. Повторный поиск пропускается,
если сверка геометрии, области, слоёв и допуска подтверждает прежнее состояние.
Проверка корректности создаваемого DXF сохраняется.

«Дубли» ищет полностью совпадающие объекты в пределах одного слоя, независимо от
направления и начальной точки замкнутого контура. Частичное наложение, близкие контуры
и геометрия с другим разбиением на сегменты не считаются гарантированными дублями.
В начале проверки дубли автоматически переносятся: один оригинал остаётся, копии попадают в
непечатные слои `_DXF_DUPLICATES__<исходный слой>__<код>` и ничего не удаляет.
Они исключены из дальнейшей проверки и DXF. Затем проверяется оставшаяся геометрия
в исходной области выделения и выбранных слоях. Категории и результаты расположены:
дубли, нулевые, наложения, пересечения, открытые. Наложения и пересечения рассчитываются
совместно, открытые контуры добавляются последними. Счётчик дублей показывает число перенесённых копий.
Перенос отменяется через Ctrl+Z (после отмены обновления меток, если оно было).
При отмене дальнейшей проверки перенос сохраняется. Объекты в группах и заблокированные
копии останавливают проверку до переноса; их нужно проверить вручную.
Источник CDR автоматически не сохраняется. Общая проверка перед экспортом может переносить дубли в технические слои.
Номера меток: нулевые сверху, наложения слева, пересечения справа, открытые снизу,
дубли справа сверху. Номера раздвигаются и соединяются выносками с точными местами.

Ход экспорта, журнал, отмена и подтверждение предупреждений показаны прямо во вкладке
«Экспорт». Отдельное окно прогресса больше не запускается из основного интерфейса.
Во вкладке «Проверка» итог виден над списком проблем, с областью проверки и историей
за текущий сеанс. Отмена, пропуски и пустая выборка не отмечаются как проверка без ошибок.
На панели две кнопки: DXF и «Проверить». Они открывают нужную вкладку одного окна.
Соединение — во вкладке «Оптимизация»: весь видимый лист или только выделенное.
Каждый слой и каждое оформление обрабатываются отдельно; между слоями соединений нет.
Предпросмотр рассчитывается по кнопке «Проверить». Изменение области, выделения
или допуска требует новой проверки. Кнопки «Применить» и «Отменить» (сброс предпросмотра). Применённое изменение отменяется Ctrl+Z.
Галочка «Объединить в непрерывные векторы» собирает участки на пересечениях
без повторного использования линий. Результат может быть открытым или замкнутым.
Новые соединения ограничены допуском; разное оформление обрабатывается отдельно.
Ход применения, время и итог показаны во вкладке; итог сохраняется после пересчёта.
Для построенной сети число векторов минимально; выбор перемычек не гарантирует
глобального оптимума среди всех возможных соединений.
Памятка и обратная связь — во вкладке «Слои и помощь».
Светлая и тёмная темы выбираются вручную и запоминаются.
Обратная связь открывает черновик публичного GitHub Issue, а не отправляет его без подтверждения.
Проверка показывает проблемные места и может добавить удаляемые непечатные метки.
Проверка идёт строго внутри каждого слоя. Допуск кривых настраивается
от 0,001 до 1 мм (по умолчанию 0,1 мм). Есть прогресс этапов и отмена. Итог каждого слоя сразу записывается в журнал,
включая нулевые результаты; при отмене завершённые слои остаются в истории.
Область проверки: весь текущий лист (по умолчанию) или только выделенное в CorelDRAW.
Скрытые и технические слои, INFO и # исключены из проверки и оптимизации.
Криволинейные пересечения проверяются приближённо, это кандидаты
для визуальной проверки, а не сертификат отсутствия дефектов.
Инструкция для пользователей: `corel_export/README_RU.txt`.
Поддерживаемая сборка: CorelDRAW 2024 x64 с VBA.

## Разработка

Исправления тестовой сборки 0.11.5 проверены на геометрии рабочего тестового файла:
поиск дублей отдельных подконтуров составных кривых, перенос только лишних подконтуров,
исключение обычных стыков открытых концов из пересечений и независимый лимит результатов
для каждого слоя. Регрессионные проверки рабочего файла выполняются локально; производственные данные не входят в публичный репозиторий.

- `corel_export/`: макрос VBA, окна, установщик и упаковка.
- `engine/`: самостоятельная копия движка конвертации и оптимизации.
- `test_corel_*.py`: автоматические тесты.

```powershell
python -m pip install -r requirements.txt
python -m unittest discover -p "test_corel_*.py"
python build.py
```

`build.py` пересобирает конвертер и установщик, используя сохранённый GMS.
Перед каждым выпуском повысить `VERSION` в `corel_export/version.py`.
Имя EXE и версия в окне установщика берутся из этого файла.
После изменения VBA или формы GMS необходимо пересобрать через
`corel_export/build_macro.py` на компьютере с CorelDRAW и VBA.
Этот скрипт изменяет только проект макроса SkladCorelDXF, не чертежи.

Проект выделен из `s_sklad_40`. Старые внутренние имена SkladCorelDXF
и идентификаторы панели сохранены для совместимости установленных копий
и горячих клавиш; они не означают зависимости от склада.
Исходный движок гаджета Aspire оставлен в прежнем проекте.

В оптимизации поиск и автоматический перенос дублей на технические слои выполняются до расчёта соединений. Перенос отражается в журнале и отменяется отдельным Ctrl+Z; отмена предпросмотра его не отменяет. Перед применением повторно проверяется отсутствие дублей.

В оптимизации по умолчанию выбран весь лист. Проверка и расчёт запускаются только кнопкой «Проверить»; изменение параметров или чертежа требует новой проверки. Отчёт проверки сохраняется в журнале оптимизации.
